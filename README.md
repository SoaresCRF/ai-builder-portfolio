# AI Builder Portfolio

A portfolio of projects that use AI as leverage: end-to-end solutions to real business problems,
from prompt to deployed product.

The focus is not on how models work internally, but on **what can be built with them**:
automations that save hours, internal tools, dashboards, agents, and product demos.

## Projects

Each project lives in its own folder with its own README (problem, solution, stack, how to run, and results).

| Project | Folder | What it demonstrates |
| --- | --- | --- |
| Meeting Notes API | [`meeting-notes-api/`](meeting-notes-api/) | Serverless API with structured output (JSON + schema) |
| Invoice Processing Automation | [`invoice-processing-automation/`](invoice-processing-automation/) | n8n automation with AI document extraction |
| Business Metrics Dashboard | [`business-metrics-dashboard/`](business-metrics-dashboard/) | AI-assisted data analysis with natural-language questions |
| Contract Review Tool | [`contract-review-tool/`](contract-review-tool/) | Deployed internal tool built with vibe coding |
| Sales Research Agent | [`sales-research-agent/`](sales-research-agent/) | Agent orchestration with Claude, GPT, and Gemini |
| Interview Coach Demo | [`interview-coach-demo/`](interview-coach-demo/) | Product demo built from scratch in 3 days or less |

## Skills covered

- Advanced prompt engineering
- Agent orchestration (Claude, GPT, Gemini)
- Automations with n8n, Make, and Zapier
- Vibe coding (Cursor, v0, Bolt, Replit)
- APIs without a heavy backend (serverless functions)
- AI-assisted data analysis

## Conventions

- Data is always public, synthetic, or fictional — no real personal data.
- Secrets (API keys) live in `.env`, never in the repository; each project ships a `.env.example`.
